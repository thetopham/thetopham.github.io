Development prototype

Manfred · Wearable AI companion

A wearable-to-phone-to-service pipeline for collecting audio and visual context. The implementation separates the Android companion, media services, and downstream knowledge export.

  • Android/Flutter companion with a Bluetooth LE audio bridge, durable upload buffering, and capture controls.
  • Python ingestion, voice activity detection, transcription, search, retention/deletion, and image-centered episodes.
  • Explicit export contracts and independent source/Android validation rather than direct dependencies on private knowledge or fleet packages.

Current limits: EyeVue/E09 photo capture is experimental. Source tests do not establish reliable end-to-end hardware operation or instant high-resolution image transfer over Bluetooth.

This is a development prototype, not a finished always-on assistant. Personal captures and runtime configuration are not part of this portfolio.

Private development project

Demerzel · Local AI orchestration

A system for selecting work, running bounded local-AI tasks, and surfacing artifacts for review. The goal is useful, inspectable work rather than an unattended stream of model output.

  • Durable task queues, worker workspaces, sandboxed execution, heartbeats, stall handling, and preemption.
  • Review bundles, artifact tracking, metrics, and an operator-facing control center.
  • Separate knowledge, execution, and fleet-control components connected through validated interfaces and bounded calls.

Current status: Worker dispatch is paused following the architectural separation, pending runtime acceptance. This describes implemented architecture, not a currently running autonomous service.

The implementation remains private. This overview excludes personal context, recordings, credentials, host inventory, and operational configuration.
